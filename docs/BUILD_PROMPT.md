# Implementation prompt — Agua a Tiempo MX
Implement docs/PACKET.md as a small static web application.

Use HTML, CSS and JavaScript with no paid dependencies or API keys.
Keep the UI Spanish, responsive and keyboard accessible.
Use only explicitly fictional data and in-memory edits.
Always display DEMO - Datos ficticios.

Build in separately testable increments:
1. Incident form, strict validation, evidence gaps and correction state.
2. Simulated timestamped reserve readings and fictional GeoJSON matching.
3. Actual synthetic-data logistic regression with held-out evaluation.
4. Human-role simulation, unsent SMS preview and offline-contact script.
5. Full-cost and 70/30 payment scorecard with evidence denominators.

Acceptance:
- ML never confirms events, overrides rules or determines payment.
- No real SMS, official authorization or pilot outcomes are claimed.
- Missing/stale source blocks the reviewed-ready state.
- Editing evidence invalidates prior review.
- No-phone/no-storage cases retain access.
- Zero denominators show inconclusive.
- Unverified benefits show Not demonstrated.
- All test outcomes are recorded only after execution.

Follow the Packet commit plan.
Deploy the first working version, document an actual bug, fix and retest,
then deploy again. Complete the screenshot-based fresh-chat persona test
and fix the worst observed confusion.
End every session with updated DECISIONS.md, next move, commit and push.
